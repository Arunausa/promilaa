# Promilaa Website Specification

Build a premium, modern fashion eCommerce website for **Promilaa** with
a Zara/COS-inspired aesthetic. Include homepage, men/women collections,
product pages, cart, checkout, authentication UI, responsive design,
Framer Motion animations, Next.js + React + Tailwind + TypeScript +
shadcn/ui, SEO, reusable components, and dummy product data.
