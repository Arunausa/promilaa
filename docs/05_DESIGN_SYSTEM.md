# Design System

Project: Promilaa

Version: 1.0

Status: Production

---

# Overview

Promilaa is a premium women's fashion brand.

The UI must feel elegant, luxurious, modern and minimal.

Avoid template-looking designs.

The website should look closer to premium brands than typical Bangladeshi eCommerce websites.

Design Inspiration

- Zara
- COS
- Mango
- Massimo Dutti
- Aritzia

Never copy any brand.

Use them only as quality references.

# UI Philosophy

Less is more.

Whitespace is a feature.

Typography should carry the design.

Large product images.

Simple layouts.

No unnecessary borders.

No excessive gradients.

No flashy effects.

# AI Agent Rules

Do not use generic eCommerce templates.

Avoid excessive colors.

Avoid clutter.

Prioritize whitespace.

Every page must feel premium.

Maintain consistent spacing.

Maintain consistent typography.

Reuse components.

Never duplicate UI.

Animations must improve UX, not distract users.

Every screen should feel production-ready.
