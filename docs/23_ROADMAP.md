# Vision

Promilaa aims to become one of Bangladesh's leading premium women's fashion brands, specializing in high-quality One Piece, Two Piece, and Three Piece collections with a seamless online shopping experience.

Version 1 focuses on building a reliable, secure, and scalable eCommerce platform. Future versions expand into automation, personalization, analytics, and nationwide logistics.

# AI Agent Rules

Always prioritize Version 1 features before implementing roadmap items.

Do not build future features unless explicitly requested.

Design Version 1 architecture to be extensible so roadmap features can be added without major refactoring.

Avoid premature optimization or unnecessary complexity.

Keep business logic modular and scalable.

Treat this roadmap as guidance for future development, not as immediate implementation requirements.
