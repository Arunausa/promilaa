# UI / UX Guidelines

Project: Promilaa

Version: 1.0

Status: Production

# Overview

Promilaa must provide a premium, modern, elegant and effortless shopping experience.

Every page should feel clean, responsive and fast.

The UI should guide the customer naturally from discovering products to completing an order.

# Design Rules

Keep interfaces clean.

Avoid unnecessary elements.

Every component should have a purpose.

# AI Agent Rules

Every page must feel premium.

Never use generic templates.

Maintain consistent spacing.

Keep typography consistent.

Use reusable components.

Design mobile-first.

Optimize for conversions without making the UI feel cluttered.

Every CTA should be clear, visible and purposeful.

Focus on trust, simplicity and speed above everything else.
