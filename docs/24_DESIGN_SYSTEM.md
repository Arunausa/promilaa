# AI Agent Rules

Every UI must follow this Design System.

Never invent new spacing, colors or typography outside this document.

Always reuse existing design tokens.

Maintain visual consistency across customer and admin interfaces.

Prioritize whitespace, readability and premium aesthetics.

Avoid cluttered layouts.

Keep animations subtle and purposeful.

Every component must be responsive, accessible and production-ready.

The final experience should feel comparable to premium global fashion brands while remaining optimized for Bangladeshi users.
